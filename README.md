# NovaPay - API Gateway Seguro y Módulo de Autenticación (Semana 3) Este repositorio contiene la implementación del API Gateway seguro para la fintech **NovaPay**, desarrollado en FastAPI y alineado con los estándares de **OWASP Top 10** y la **Ley 1581 de 2012 / GDPR**. ## 🔒 Características de Seguridad Implementadas 1. **Gestión Segura de Credenciales**: Uso de variables de entorno (`.env`) cargadas con `python-dotenv` para evitar exponer llaves en texto plano. 2. **Encriptación de Contraseñas**: Cifrado seguro utilizando el algoritmo `bcrypt` (`bcrypt.hashpw` con salt dinámico). 3. **Autenticación JWT**: Generación y firma de tokens de acceso (`PyJWT`) para inicio de sesión de usuarios. 4. **Validación de Entradas (Regex)**: * Filtro en el campo Nombre para prevenir inyecciones de código (XSS). * Exigencia de complejidad en la contraseña (mínimo 8 caracteres, una mayúscula y un número). 5. **Cumplimiento GDPR / Ley 1581**: Validación obligatoria de consentimiento explícito de datos. ## 🚀 Endpoints Disponibles * `POST /register`: Registro seguro de usuarios. * `POST /login`: Autenticación y generación de Token JWT. ## 🛠️ Instalación y Ejecución ```bash pip install -r requirements.txt python -m uvicorn main:app --reload
